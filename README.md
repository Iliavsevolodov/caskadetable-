# MULTIKIDS 🚀

Интерактивный веб-сервис для самостоятельного изучения таблицы умножения и деления детьми 8–10 лет.

## Что уже работает

- обучение таблицам ×2–×9 через группы предметов, повторное сложение, сетку и числовую линию;
- адаптивная тренировка: выбор ответа, самостоятельный ввод, пропущенное число, верно/неверно, текстовые задачи;
- деление и математические семьи;
- автоматический возврат к ошибочным и медленным примерам;
- «Мои сложные примеры»;
- мини-игры: «Лопни шарик», «Память», «Найди пару», «Ракета», «Построй башню»;
- ежедневная смешанная тренировка;
- проверка знаний на 10/20/30 вопросов;
- режим «60 секунд» с локальным рекордом;
- прогресс по таблицам, звёзды, серии и достижения;
- локальное хранение без регистрации и backend;
- звуки через Web Audio API и короткие CSS-анимации;
- адаптивный интерфейс для телефона, планшета и компьютера.

## Стек

Next.js + React + TypeScript + Tailwind CSS. Данные сохраняются только в `localStorage` браузера.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Проверка production-сборки

```bash
npm run typecheck
npm run build
```

Название приложения вынесено в константу `APP_NAME` в `components/MultiKidsApp.tsx`, поэтому его легко заменить.
